Releases and changes

What changes in NetDoc from version to version. NetDoc tells administrators on the dashboard when a new release is available – installing it is always up to you.

Installing an update: create a backup (Settings → Backup), then on the server set NETDOC_VERSION= in the .env file to the new version and run docker compose pull && docker compose up -d. The database is upgraded automatically on startup. Details are in INSTALLATION.md inside the installation package.

NetDoc 1.3.1 · 29 October 2026

New

  • System device types can be customised. Switch, printer, workstation & co. can now be edited: name, icon, colour, features (e.g. credentials for printers, ports, rack mounting) and default ports. “Reset to default” restores the shipped values. Only deleting them and the internal name stay locked.

Improved

  • Credential scopes: the hints now explain exactly who sees a credential without its own scope (users with a scope only on devices that have one of their scopes).
  • The checkbox on credentials is now called “Linkable in password manager” and explains what it does (selectable as a linked asset, the password is not shown there).

Update notes

  • The system device types are copied into your installation once; devices keep their type. As always, we recommend a backup first (Settings → Backup).

NetDoc 1.3.0 · 28 October 2026

New

  • Scopes for individual credentials. A credential on a device can now have its own scopes – then only members of those scopes can see it. Example: the technicians see and patch the switches, but the switch credentials are visible to IT only. Credentials without their own scope behave as before. Also available as a bulk action in the device list (“Credential scopes”); users who cannot see some credentials get a “hidden” notice on the device.
  • Completing recurring reminders asks for the next date. NetDoc offers the next date as scheduled, counted from today, or any date you choose (e.g. the new certificate expiry) – or you can end the recurrence.

Improved

  • VLANs on ports and port groups (LAGs) are sorted by number, also right after adding them; links are grouped by type.
  • The device detail view only includes credentials the user is allowed to see.

Update notes

  • Database changes are purely additive (one new table). Existing credentials stay visible as before.

NetDoc 1.2.0 · 16 October 2026

New

  • Set up sign-in with Microsoft (Entra ID) inside the app. Tenant ID, application ID and client secret now live under Settings → “Sign-in with Microsoft” instead of the .env file. Includes step-by-step instructions for the Entra portal, the redirect URI ready to copy, and “Check credentials”, which also reports whether the permission for the employee sync has been granted.
  • Employee sync with Entra ID uses the same app registration – sign-in with Microsoft does not have to be enabled for it.
  • Update notice. Once a day NetDoc checks whether a new release is available and shows it to administrators on the dashboard and under Settings → Updates, with instructions. Only the installed version number is transmitted; the check can be turned off.
  • The installed version is shown under Settings → Updates.

Update notes

  • Existing MICROSOFT_* values from the .env file are imported once on first start and can be removed from the .env afterwards.
  • Database changes are purely additive (one new table, one new column).
